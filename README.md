# History Study

Мобильное приложение для изучения всеобщей истории в 6 классе. Это не конструктор курсов: приложение собрано вокруг одного учебника и его 24 параграфов.

## База знаний

Все источники имеют разные задачи — это важно, чтобы не смешивать пересказ, задания и первоисточник.

| Ресурс | Роль в базе |
| --- | --- |
| Учебник «Всеобщая история. История Средних веков. 6 класс» | Проверка фактов, терминов и дат; привязка к страницам |
| [Конспекты](https://6класс.рф/konspekty-po-vseobshhej-istorii/) | Основной объясняющий текст темы |
| [Тесты](https://6класс.рф/vsemirnaja-istorija-testy/) | Детерминированные задания в конце темы |
| ВИ-6-КР-1 | Отдельная проверочная работа после изучения раздела |

`src/data/knowledgeBase.ts` — единственный каталог учебного курса: шесть глав, §1–24, диапазоны страниц учебника и статусы переноса. Сам учебник в репозиторий не копируется.

На данный момент как полноценные интерактивные уроки подключены §4 и §7. Остальные §1–24 уже внесены в каталог и показывают точные страницы учебника; их объяснения и тесты переносятся только после сверки с соответствующими источниками.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который появится в терминале, на Mac или в той же сети на iPhone.

## Принципы

- Контент хранится отдельно от экранов приложения.
- Нет AI API: тестовые задания имеют заранее заданные ответы, а открытые ответы снабжены чек-листом самопроверки.
- Прогресс, очки и цель накоплений хранятся локально на устройстве.
- Учебник остаётся источником для уточнений; оригинальные страницы будут подключены отдельно, когда понадобится просмотр PDF в приложении.
