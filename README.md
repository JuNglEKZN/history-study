# History Study

Мобильный MVP для изучения школьной истории по учебнику.

Сейчас в проекте есть один полностью подключённый параграф: **§ 4 «Европа в IX—XI вв.»**. Его факты, даты и задания привязаны к сканам стр. 39–48, которые открываются внутри приложения.

## Запуск

```bash
npm install
npm run dev
```

## Принципы MVP

- Интерфейс и учебный контент разделены: данные первого параграфа находятся в `src/data/history6.ts`.
- Прогресс и цель накоплений хранятся локально на устройстве.
- Задания проверяются детерминированно, без AI API; очки за каждое верное задание выдаются только один раз.
- Скан учебника — первоисточник: в каждом учебном блоке есть ссылка на конкретную страницу.

Для добавления следующей темы сначала нужны соответствующие страницы учебника. Затем контент добавляется в отдельный набор данных, а UI не меняется.
